# Amendment 2026-11-26 (3): recording the test states changes a file freeze 2 hashes

**Stage.** After freeze 1 (commit 117ae28, `frozen/design.json` sha256
`f55415351f971d7726a81708ef2b3bd0508e6f12b30c7916dad564224999d140`) and the amendments
`2026-11-26.md` and `2026-11-26-2.md` (commit adbf1dd), after the pilot, before main training.
DESIGN.md is not changed.

**What existed at this point.** The same as in amendment `2026-11-26-2.md`, and in addition
`results/pilot/confirmation.json` (sha256
`4c7512db7ceeae56a0415d51370ce9645837b62acc9522e49aa78a4a3aa81fc0`, commit df80807): the pilot
confirmation, the only intervention error computed so far (`mlp-shortcut` and `mlp-twin` on pilot
states). No main run, no freeze 2, no test state, no gate, no result.

**What was found, and the evidence.** `freeze.py --stage 2` records the sha256 of
`data/main/manifest.json` in `frozen/models.json`. The test states are made after freeze 2, and
`make_data.py --split test_states` records them in that same `manifest.json`; `score.py` then
runs `check_frozen(2)`, which finds `manifest.json` changed since freeze 2 and refuses to score.
The test states would have existed by then, so a fix at that point would have meant a new test set.
Found with a new rehearsal script, `scripts/rehearse_scoring.py`, which runs `freeze.py --stage 2`,
the recording of test states and `score.py` unchanged in a scratch copy of the repo, with untrained
checkpoints for every run (no model's intervention error after training is computed) and Phase 0's
smoke states as stand-in test states. In the run order it failed with `changed since the freeze:
['data/main/manifest.json']`; with freeze 2 rewritten after the test states (in the copy only),
`score.py` ran to the end with no format error, so nothing further down the scoring path fails.

**The fix.** `make_data.py` records `test_states` and `test_history` in
`data/main/manifest_test.json`, and `score.py` reads the test states' sha256 from there. The
manifest freeze 2 hashes stays unchanged. No rule, threshold or reading changes, and no data or run
is affected (every file written so far is recorded where it was). A new test checks where each
entry is recorded; the rehearsal in the run order now passes: `score.py` exits 0 and the result
conforms to the format.
